# Changelog

## [1.1.0](https://github.com/chang196700/newline/compare/v1.0.0...v1.1.0) (2026-09-07)

### Features

* preserve unchanged Git file endings and automate semantic releases ([bcc9dec](https://github.com/chang196700/newline/commit/bcc9dec97bec1dc384bd9ef81c4b32450d2a67f8))

Release entries are generated by Semantic Release from Conventional Commits.
Versions are released from `master`: `fix:` creates a patch release, `feat:` a
minor release, and breaking changes a major release. Documentation and maintenance
commits alone do not create a release. Entries below 1.0.0 are retained from the
legacy changelog.
